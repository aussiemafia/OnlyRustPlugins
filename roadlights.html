RoadLights

RoadLights brings Rust's roads to life by automatically adding functional lighting to supported roadside power poles across your map.

Designed as a plug-and-play solution, RoadLights automatically detects supported road poles and places the appropriate lights without requiring server owners to manually position them.

The lights operate automatically using Rust's day/night cycle. They switch on around dusk and switch off around dawn, following Rust's dynamic sunrise and sunset times.

Features

  • Automatic road light detection
  • Automatically installs lights onto supported roadside poles
  • Dynamic dusk and dawn operation
  • Uses Rust's actual sunrise and sunset cycle
  • Automatic light activation at night
  • Automatic shutdown during daylight
  • Natural dusk/dawn transition effect
  • Supports multiple roadside pole types
  • Multiple lights supported on applicable pole types
  • Automatic detection after server/plugin startup
  • Performance-conscious operation
  • No manual light placement required
  • No dependencies
  • Plug-and-play installation
  • Carbon compatible

Installation

  1. Download RoadLights.cs.
  2. Place the file into your server's plugins folder.
  3. Reload RoadLights.

Carbon

c.reload RoadLights

Oxide/uMod

oxide.reload RoadLights

RoadLights will automatically scan the map for supported roadside poles and handle the lighting system. There is no separate configuration or calibration process required for normal installation.

Admin Permission

roadlights.admin

Give permission to one admin — Carbon:

c.grant user STEAMID roadlights.admin

Give permission to admin group — Carbon:

c.grant group admin roadlights.admin

Automatic Day/Night Lighting

RoadLights follows Rust's dynamic sunrise and sunset system. At dusk, the roadside lights automatically activate. At dawn, the lights automatically switch off. No timers need to be manually configured for normal operation.

Plug & Play

Install → Reload → RoadLights handles the rest.

No manually positioning hundreds of lights around your map. No manually setting every roadside pole. No complicated setup procedure.
